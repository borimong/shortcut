※ 이 문서는 캡스톤 프로젝트용 가상 규정이다. 실제 지자체 규정이 아니다.

## 2.1 허가 대상과 신청
한강 둔치에서의 영상 촬영은 사전 허가가 필요하며, 촬영일 5일 전까지 신청한다.

## 2.3 허가 시간대
기본 허가 시간대는 10시부터 17시까지다. 주말에는 자전거 도로 이용자가 많아 촬영 구역을 통제할 수 없다.

## 3.2 일정 변경과 취소
강수 확률이 높아 촬영을 미루려면 촬영일 전날 17시까지 변경 신청을 한다.
