# 할 일: 최적화 가중치 조정
감독 지시를 반영해 여섯 가지 최적화 기준의 가중치를 정하세요. 각 값은 0과 1 사이이고, 합은 코드가 1로 맞춥니다.
- location: 장면 의도와 장소 적합도
- equipment: 장비 가용성과 추가 대여
- weather: 우천과 일조 위험
- budget: 비용 절감
- time: 이른 종료와 대기 시간
- distance: 이동 거리
예산 한도는 하드 제약이라 가중치와 관계없이 유지됩니다. 지시와 관계없는 기준은 현재 값 근처로 둡니다.

## 감독 지시
$instruction

## 현재 가중치
$weights
