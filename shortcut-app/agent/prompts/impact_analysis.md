# 할 일: 변경 영향 분석
아래 변경 이벤트가 오후 촬영 블록에 주는 영향을 조사하세요. 필요한 도구를 직접 고르세요.
- 온톨로지에서 변경이 걸린 노드(씬, 배우, 장소, 장비)와 그 주변을 조회해 영향 범위를 묶습니다. 노드 ID 예: SCENE:S12, ACTOR:1, LOCATION:1, EQUIPMENT:2, PLAN:$shoot_day_id-1
- 변경 대상 블록의 노드 ID는 $block_node입니다. 블록에서 깊이 1이면 블록의 씬, 장소, 장비, 후보안이 나오고, 깊이 2면 씬의 배우와 같은 장비·장소를 쓰는 같은 촬영일의 다른 블록까지 넓어집니다.
- find_impacted_entities를 부를 때는 shoot_day_id(값 $shoot_day_id)를 함께 넘기세요. 배우와 장비는 다른 촬영일도 함께 쓰므로 넘기지 않으면 다른 촬영일의 씬과 블록이 섞여 나옵니다.
- 날씨, 재난 문자, 가용 자원 가운데 이번 변경 판단에 필요한 것을 조회합니다.
- 변경 대상 블록 씬의 대본 요구(실내/실외, 낮/밤, 세트 고정, 필수 장비)는 아래 블록 정보에 있습니다. 배우 일정이 걸린 변경이면 get_availability로 그날 windows, busy를 보고, 다른 날 일정이 필요하면 get_actor_schedule을 부릅니다.
- 충분히 조사했으면 도구를 더 부르지 말고 조사 결과를 세 문장 이내로 정리하세요.
