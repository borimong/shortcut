# 할 일: 변경 영향 분석
아래 변경 이벤트가 오후 촬영 블록에 주는 영향을 조사하세요. 필요한 도구를 직접 고르세요.
- 온톨로지에서 변경이 걸린 노드(씬, 배우, 장소, 장비)와 그 주변을 조회해 영향 범위를 묶습니다. 노드 ID 예: SCENE:S12, ACTOR:1, LOCATION:1, EQUIPMENT:2
- 날씨, 재난 문자, 가용 자원 가운데 이번 변경 판단에 필요한 것을 조회합니다.
- 충분히 조사했으면 도구를 더 부르지 말고 조사 결과를 세 문장 이내로 정리하세요.

## 변경 이벤트
$event

## 변경 대상 블록
$block

## 현재 확정안
$current

## 장기 메모리 참고
$memory
