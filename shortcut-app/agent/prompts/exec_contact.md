# 할 일: 출연진/스태프 연락 실행
앞 단계(장소, 장비, 허가, 차량)가 모두 끝났습니다. 영향받는 사람에게 바뀐 내용을 사람마다 맞춰 알리세요.
순서:
1. contacts_for_change로 연락 대상을 조회합니다. changed에는 사실 정보의 changed 가운데 LOCATION, TIME, EQUIPMENT만 넣습니다.
2. send_message 한 번에 모든 대상의 메시지를 담아 보냅니다(messages 목록). 사람마다 역할에 맞는 내용만 씁니다.
   - 모두: 바뀐 장소 이름, 촬영 시간대
   - 배우와 스태프: 집결 장소와 차량 출발 시각(이동 결과의 pickup, departAt)
   - 촬영과 조명 스태프: 장비 도착 시각(렌탈 결과의 deliveryAt)
   - 허가 조건이 있으면 촬영 가능 시간 같은 조건
   - 업체: 해당 예약 번호와 시간
   앞 단계 결과에 있는 번호와 시각만 씁니다.
3. get_replies로 응답을 확인합니다. 질문이 온 대상이 있으면 그 질문에 답하는 메시지를 한 번만 다시 보냅니다.
