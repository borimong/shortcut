# 할 일: 최적안 설명과 체크리스트
업무 규칙 엔진이 고른 최적안 1개를 승인자가 판단할 수 있게 설명하세요.
- explanation: 무엇이 1안 대비 어떻게 바뀌었는지, 왜 이 조합이 가장 좋은지(점수와 핵심 근거), 비용과 이동 변화를 5문장 이내로 씁니다.
- checklist: 하드 제약 8개 범주마다 PASS 또는 WARN과 짧은 메모, 근거 chunk_id를 씁니다. 근거 조항 목록에 있는 ID만 씁니다.
- SCRIPT 항목의 근거는 대본 씬 원문(search_script 결과) chunk_id입니다. "엔진 경고"에 대본 경고(야외 장면을 실내에서, 선호 장비 없음)가 있으면
  SCRIPT는 PASS로 두고 메모에 그 경고를 적고, 설명에 한 문장으로 밝히고, 미확정 항목에 "연출감독, 실내 촬영 연출 확인, 승인 시"처럼 넘깁니다.
- 선택한 후보에 "씬 순서 변경"이 있으면 엔진이 배우 일정이나 해 때문에 블록 안 씬 순서를 바꾼 것입니다. 설명에 새 순서를 씬 코드와
  시각으로 쓰고(예: "S19를 14:00~14:30에 먼저 찍고 S18을 14:30~16:00에 찍습니다"), 어느 배우의 어떤 종류 일정 때문인지 한 문장으로 밝히고,
  미확정 항목에 "조감독, 바뀐 씬 순서로 배우 콜타임 다시 공지, 승인 즉시"처럼 넘깁니다. 일정 사유는 종류만 씁니다.
- unresolved: 승인 뒤 사람이 처리할 일을 "담당, 할 일, 기한" 형식으로 씁니다. 예: "제작실장, 배우 A 소속사에 일정 변경 통보, 승인 즉시(계약 제9조)"
- checklist의 WARN은 실제로 위반 위험이 남아 있을 때만 씁니다. 승인 뒤에 하는 통보나 예약 확정은 PASS로 두고 메모에 적습니다.
- "자체 검토 피드백"이 있으면 그 지적을 하나씩 고친 결과가 설명, 체크리스트, 미확정 항목에 드러나야 합니다.
- needs_more_info: 체크리스트를 채우기에 근거가 부족하면 true와 부족한 범주를 missing에 씁니다.
