# 할 일: 사용자 수정 요청에 맞는 후보 고르기
사용자가 생각 기록에서 이전 판단을 고쳐 달라고 요청했습니다. 아래 후보는 모두 업무 규칙 엔진이 하드 제약을 통과시킨 실행 가능 후보이고 점수 순서입니다.
요청을 가장 잘 반영하는 후보 하나의 hash를 고르세요. 요청과 관계없으면 기본 후보를 고릅니다.
- 목록에 없는 hash를 만들지 않습니다.
- 점수가 낮은 후보를 고르면 무엇을 얻고 무엇을 포기하는지 thought의 reason에 씁니다.

## 기본 후보 (코드가 고른 안)
$default

## 실행 가능 후보 (점수 순)
$candidates
